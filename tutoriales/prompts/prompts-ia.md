# Prompts de IA - Colección Optimizada

Una colección de prompts listos para usar. Copia, pega y adapta según tus necesidades.

## 📝 Prompts para Escritura

### Blog Post Generator
```
Escribe un artículo de blog sobre [tema] dirigido a [audiencia]. 
Estilo: [formal/casual/técnico]
Largo: [palabras]
Incluye: introducción, 3 secciones principales, conclusión, CTA.
```

### Email Marketing
```
Escribe un email promotional para [producto/servicio].
Tono: [tono]
CTA: [acción deseada]
Límite: 150 palabras
PSA: urgencia moderada sin ser invasivo
```

## 💻 Prompts para Programación

### Code Review Assistant
```
Revisa este código y sugiere mejoras en:
- Legibilidad
- Performance
- Security
- Mantenibilidad

[pega tu código aquí]
```

### Bug Hunter
```
Tengo este error: [descripción del error]
Mi código: [código]
Entorno: [Node.js/Python/etc versión]
Qué está mal y cómo lo arreglo?
```

## 📊 Prompts para Análisis

### Data Insights
```
Tengo estos datos: [data]
Qué patrones ves?
Qué conclusiones puedo sacar?
Qué acciones recomendarías?
```

### Competitive Analysis
```
Analiza a [competidor]:
- Fortalezas
- Debilidades  
- Oportunidades de diferenciación
- Estrategia recomendada para nosotros
```

## 🎯 Prompts para Marketing

### Copy for Ads
```
Escribe un copy publicitario para [plataforma] sobre [producto].
CTA: [acción]
Tono: [tono]
Límite: [caracteres]
Argumento: enfocarse en [beneficio principal]
```

### Content Calendar
```
Crea un calendario de contenido para [industria] para [mes].
Plataforma: [redes sociales]
Frequencia: [veces/semana]
Tema: [tema principal]
```

---

💡 **Tip:** Mejor es ser específico. Cuantos más detalles, mejor respuesta.
