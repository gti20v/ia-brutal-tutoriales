# Freebuff - Tutorial de Instalación GRATIS

**Freebuff** es un agente de IA que vive en tu terminal. Es GRATIS, no necesita API Key, y es completamente ilimitado. Es la alternativa real a Cursor, Claude Code y Lovable.

## ¿Por qué Freebuff?

- 💰 **Completamente gratis**
- 🔑 **Sin API Key requerida**
- ∞ **Sin límites de uso**
- 🚀 **Rápido y directo**
- 📍 **Vive en tu terminal**

## Requisitos previos

Antes de instalar Freebuff, asegúrate de tener:

- **Node.js** (v16 o superior) - [Descargalo aquí](https://nodejs.org/)
- **npm** (viene con Node.js)
- **Terminal** (CMD en Windows, Terminal en Mac/Linux)
- **Conexión a internet**

Verifica que los tienes instalados:

```bash
node --version
npm --version
```

## Instalación paso a paso

### 1. Abre tu terminal

**Windows:** 
- Presiona `Win + R`
- Escribe `cmd` y presiona Enter

**Mac:**
- Presiona `Cmd + Espacio`
- Escribe `terminal` y presiona Enter

**Linux:**
- Presiona `Ctrl + Alt + T` o abre tu terminal favorito

### 2. Navega a tu proyecto

```bash
cd ruta/de/tu/proyecto
```

**Ejemplo:**
```bash
cd C:\Users\SamuSVQ\proyectos\mi-app
```

### 3. Instala Freebuff

Copia y pega este comando en tu terminal:

```bash
npm install -g freebuff
```

Espera a que termine. Deberías ver algo como "added X packages".

### 4. Inicia Freebuff

```bash
freebuff
```

¡Eso es! Freebuff está corriendo en tu terminal. Verás un interfaz interactivo.

                                    ## Comandos útiles

                                    | Comando | Qué hace |
                                    |---------|----------|
                                    | `freebuff` | Inicia Freebuff |
                                    | `exit` o `Ctrl+C` | Sale de Freebuff |
                                    | `clear` | Limpia la terminal |
                                    | `npm list -g freebuff` | Verifica si está instalado |

                                    ## Solucionar problemas

                                    ### "npm: command not found"
                                    - Node.js no está instalado. [Descargalo aquí](https://nodejs.org/)
                                    - Reinicia tu terminal después de instalar

                                    ### "freebuff: command not found"
                                    - Ejecuta: `npm install -g freebuff` de nuevo
                                    - Verifica: `npm list -g freebuff`

                                    ### Freebuff se congela
                                    - Presiona `Ctrl+C` para salir
                                    - Inicia de nuevo con `freebuff`
