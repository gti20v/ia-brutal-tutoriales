## 🚀 Cómo desplegar

El sitio está preparado para **GitHub Pages**:
1. Ve a **Settings → Pages** del repositorio
2. Selecciona **Deploy from a branch**
3. Rama: `main` / Carpeta: `/ (root)`
4. Guarda y espera 1-2 minutos
