# IA BRUTAL - Tutoriales, Guías y Prompts Sin Humo

Bienvenido a **IA BRUTAL**, tu fuente de contenido educativo sobre inteligencia artificial. Aquí encontrarás tutoriales prácticos, guías paso a paso y prompts listos para usar. Sin afiliados, sin marketing, solo información real.

## 📚 Contenido

### [📋 Prompts de IA](/prompts/)
Colección de prompts optimizados para:
- **Escritura y contenido** - Redacción, blogs, copywriting
- **Programación** - Code snippets, debugging, arquitectura
- **Marketing y negocio** - Análisis, estrategia, copywriting comercial
- **Productividad** - Organización, automatización, planificación

### [🎓 Tutoriales](/tutoriales/)
